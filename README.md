# MelvorClaude

A benchmark for testing long-term planning in AI agents, using [Melvor Idle](https://melvoridle.com) as the
environment. Progress takes days of real time and only one task can be progressed at a time, so the agent is scored on
how well it sequences goals, not on individual actions. It plays only through Python action and observation scripts.

See [fast_scripts/README.md](fast_scripts/README.md) for details on the scripts.
